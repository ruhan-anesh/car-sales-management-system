# Car Sales Management System (C)

## Overview
This project is a console-based Car Sales Management System developed in C to model the core operations of a vehicle dealership. The application focuses on structured data handling, user interaction, and transaction tracking, providing a practical example of how sales and inventory workflows can be implemented in a low-level programming environment.

The system enables users to browse available vehicles, complete purchase transactions, record sales activity, and capture customer feedback through a menu-driven interface.

---

## Key Capabilities
- Inventory Display  
  View available vehicles along with pricing and stock details.

- Sales Processing  
  Simulate car purchases with customer input and transaction confirmation.

- Revenue & Sales Tracking  
  Maintain records of cars sold and calculate overall sales performance.

- Customer Feedback Collection  
  Capture and store user feedback and ratings for completed purchases.

- Structured Program Design  
  Uses C structs, arrays, and control flow to manage real-world entities and processes.

---

## Technology Stack
- Programming Language: C  
- Compiler: GCC  
- Development Environment: Visual Studio Code / CodeBlocks  
- Platform: Windows console (uses `system("cls")`)

---

## Getting Started

### Prerequisites
- GCC compiler installed  
- C-compatible development environment  

### Build & Run
1. Clone the repository: https://github.com/ruhan-anesh/car-sales-management-system
   
2. Navigate to the project directory and compile: gcc car_sales_management.c -o car_sales_management
   
3. Run the executable: ./car_sales_management

   
---

## Application Flow
1. Launch the program and select an option from the main menu  
2. View available cars and current inventory  
3. Complete a purchase by entering customer and vehicle details  
4. Review sales summaries and total revenue  
5. Submit customer feedback to evaluate service quality
