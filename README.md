# Car Sales Management System (C)

A console-based Car Sales Management System developed in C as part of an academic project.

## Features
- View available car stock
- Purchase cars with age-based discount logic
- Track sales and total revenue
- Sort cars by year and sales performance
- Collect and display customer feedback

## Technologies
- C Programming
- Structs and Arrays
- Input Validation
- Sorting Algorithms

## Notes
- Developed as part of a BSc in Artificial Intelligence
- Runs in a console environment (Windows-compatible)
